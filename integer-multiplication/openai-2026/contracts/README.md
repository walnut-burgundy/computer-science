# Shared semantic corpus v1

`mul-v1.tsv` contains exact unsigned multiplication vectors. After its comment line,
columns are operation, case ID, left bit width, right bit width, left integer (decimal),
right integer (decimal), and exact product (decimal). Widths include leading zeroes;
width zero encodes only zero. Unequal lengths are explicitly zero-extended by consumers
to max(left_bits,right_bits); retain the requested output width separately from the
canonical numerical value. Parsing must reject values outside their supplied widths.

65,536 exhaustive 8-bit pairs are followed by 168 boundary vectors. These cover the
listed widths 0 through 1025, leading zeros, unequal lengths, powers, all ones, long
carry chains, alternating bits and an explicitly fixed arithmetic sequence. Generated
by `examples/autogenerated/mul-0/Corpus.idr` through the pinned Idriç Chez compiler;
the existing Integer runtime is the independent product oracle. No candidate module
is imported. Fixed identities (zero/one/power/all-ones) cross-check this generator.
Future maintained acceptance adds an independently compiled elementary base-2 oracle,
the stage-vector TSVs, serialized limb cases, candidate-provenance gate and mutation suite.

The preserved `Model.idr` is the initial shared internal corpus: its deterministic
enumerations cover nonzero-scratch scalar networks, signed address shifts, Gaussian
phase identity and signed polynomial recovery. Its `main` is the source of inputs;
`model-results.json` records outputs/statuses. It is not yet an independent external
stage-vector file. MUL-1 must export those mathematical vectors, without requiring
the candidate to share their generator or schedule logic.

Do not infer that whole-integer candidate multiplication was tested merely because
oracle vectors were generated. Published-profile cases require separate admission.
